# capstone-data

Mirror of the computed results of the Udacity AI Mastery capstone (Δ-probed IR pipeline): corpus geometries and Hessians (B3LYP and ωB97X,
with the analytic second-route Hessians where computed), the release training sets, second-route checks, run records of the E-series and rung C,
and the standout module's records. Written nightly from the laptop by `tools/backup_data.py` in the code repository
<https://github.com/thebreadishard/udacity-capstone-plan>; paths mirror `plans/05_delta-probed-ir-pipeline/`. The psi4 logs (GB-scale) are not
mirrored. `BACKUP_LOG.md` lists every run.
